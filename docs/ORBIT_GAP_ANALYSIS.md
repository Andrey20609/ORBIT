## 1. Сводная классификация модулей

Каждый компонент классифицирован по трём категориям:
- 🟢 **РЕАЛЬНО РАБОТАЕТ (Functional):** Реализована полная логика, данные сохраняются локально или обрабатываются конвейером, протестировано юнит- и виджет-тестами.
- 🟡 **ДЕМОНСТРАЦИОННОЕ (Demo / Mock):** Интерфейс присутствует, но данные захардкожены в статических структурах (`demo_data.dart`), нет реальных сетевых вызовов, нет связи с сервисами.
- 🔴 **ОТСУТСТВУЕТ (Missing):** Компонент не реализован или существует только в виде концептуального заголовка / заглушки.

## 3. Критический путь преодоления разрыва (Bridging the Gap)

1. **Этап I (Завершение Visual Lab & Референс-экранов — Текущий):**
   - Закончить перенос референсного визуального стиля (Mail Inbox/Detail, Brain, Settings) по референс-бордам пользователя.
   - Распространить атмосферный движок с единым `sceneKey` на все разделы приложения.

2. **Этап II (Внедрение промышленного Data Layer):**
   - Заменить `orbit_state.json` на локальную базу данных SQLite (Drift) с поддержкой миграций и FTS5.
   - Реализовать сущности Workspaces («Работа», «Личное», «Проекты») с привязкой сущностей.

3. **Этап III (Реальная интеграция почты и календаря):**
   - Реализовать IMAP/SMTP клиент с TLS и OAuth 2.0 (Google & Microsoft Graph).
   - Создать фоновую очередь синхронизации с защитой от потери данных в offline.
   - Подключить чтение и запись системного календаря Android.

4. **Этап IV (Файлы, Заметки, Контакты и Единый Поиск):**
   - Создать модуль ORBIT Files (каталог вложений и кэш).
   - Создать модуль ORBIT Notes (Markdown заметки с привязкой к встречам и письмам).
   - Создать модуль ORBIT Contacts с поиском.
   - Запустить Unified Search по всем локальным репозиториям.

5. **Этап V (Интеллектуальный слой ORBIT Brain):**
   - Подключение LLM через безопасный шлюз с маскированием конфиденциальных данных.
   - Внедрение генерации саммари писем, автосоздания задач и подготовки ответов с обязательным подтверждением пользователем.
