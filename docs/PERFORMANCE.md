# Performance

Актуальный отчёт Sprint 02 находится в корневом [`PERFORMANCE.md`](../PERFORMANCE.md). Он содержит единую A/B/C-матрицу Static/Rive/Filament, фактический размер созданного APK и команды сбора raw evidence.

Все FPS, frame time, RAM, GPU, энергия, нагрев и crash/ANR остаются `NOT MEASURED`, если соответствующий device run не выполнялся. Наличие counters в коде, успешная сборка, golden-кадры или подготовленные ADB-скрипты не являются измерением производительности.
