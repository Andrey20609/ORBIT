`source/download-manifest.json` records URLs, byte sizes and MD5. `optimized/optimized-manifest.json` records derived mobile-resolution assets and SHA-256.

The official API response for `aerial_rocks_02_nor_gl_2k.jpg` listed MD5 `551acdd3266815debad8b8dcec5599c5`, while the downloaded valid 2048×2048 JPEG had MD5 `7c405cfd3308a2672c99b44e102c328e`. The file was visually validated as the expected OpenGL rock normal map; the actual hash is pinned in the downloader. This discrepancy is retained rather than hidden.

Optimized JPEGs are downsampled/cropped derivatives. Original source files are included for audit. No personal data, credentials, paid resources or network access at application runtime are involved.

`flow_light.jpg` and `flow_dark.jpg` are original programmatic gradients/glow layers generated by `tool/render_flow_backgrounds.py`; they contain no third-party imagery. `one_foreground.webp`, `atelier_foreground.webp` and `zen_foreground.webp` are alpha-masked CC0 derivatives generated by `tool/build_scene_layers.py`; hashes and mask ranges are pinned in `optimized/scene-layers-manifest.json`.

- `optimized/one_sky.webp`: CC0 pure atmosphere layer derived from `source/kloppenheim_06_puresky.jpg` (Greg Zaal / Jarod Guest).

- `optimized/one_fg.webp`: CC0 foreground terrain/meadow layer derived from `source/kloppenheim_06.jpg` (Greg Zaal).
